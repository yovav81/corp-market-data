# נתוני שוק יומיים לאג"ח — אוטומטי בענן

המאגר מוריד בכל ערב, אחרי סגירת המסחר, את טבלאות האג"ח מגלובס: קונצרני צמוד, שקלי ומט"ח, וממשלתי שקלי וצמוד. לכל סדרה נשמרים שער, שינוי, מחזור, מח"מ, תשואה ברוטו ונטו, מועד פדיון ודירוגי מעלות ומידרוג. בממשלתיות נשמרת גם הריבית הנקובה.

ההרצה מתבצעת ב-GitHub Actions, כך שהמחשב שלך לא צריך להיות דלוק ואין צורך ללחוץ על שום דבר.

## מה נשמר

| קובץ | תוכן |
|---|---|
| `data/latest.csv` | יום המסחר האחרון. אקסל העל קורא את הקובץ הזה |
| `data/daily/<שנה>/<תאריך>.csv` | צילום מלא של כל יום מסחר |
| `data/history/<שנה>.csv` | היסטוריה מצטברת: שורה לכל סדרה בכל יום, הבסיס לניתוח מרווחים היסטורי |
| `data/daily/<שנה>/<תאריך>.partial` | מופיע רק כשיום נקלט חלקית, ומפרט מה חסר. ההרצה הבאה מנסה שוב |

## הפרש ממשלתי

- `spreads.py` רץ בסוף כל הרצה ומחשב מחדש את כל ההיסטוריה ל-`data/spreads/<שנה>.csv`.
- אג"ח צמודה מול עקום ממשלתי צמוד, שקלית מול עקום שקלי קבוע; אינטרפולציה ליניארית לפי מח"מ. `extrap=1` אם המח"מ מחוץ לטווח העקום.
- מסוננות תשואות מעל 50% או שליליות ומח"מ מתחת ל-0.3. אג"ח מט"ח לא נכללות.
- היסטוריה חיצונית (תשואה ומח"מ יומיים) אפשר למזג ל-`data/history` ולהריץ מחדש.

## לוח זמנים

- שתי הרצות בכל ערב, בימי המסחר שני–שישי: ב-19:17 וב-22:47 בשעון קיץ, ושעה מוקדם יותר בשעון חורף.
- ההרצה השנייה היא גיבוי. היא מושכת נתונים רק אם הראשונה לא השלימה את היום.
- ביום בלי מסחר המחירים והמחזורים לא זזים, ולכן לא נשמר דבר.
- הרצה ידנית: לשונית **Actions**, בוחרים `market-data` ואז **Run workflow**. הרצה ידנית תמיד מושכת מחדש.
- כשהרצה נכשלת, או כשטבלה נקלטה חלקית (פחות מ-80% מהסדרות של יום המסחר הקודם), GitHub שולח מייל.

## חיבור לאקסל (Power Query)

במאגר פרטי צריך טוקן קריאה. יוצרים אותו פעם אחת:

1. GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token.
2. ב-Repository access בוחרים **Only select repositories** ואת `corp-market-data`.
3. ב-Permissions → Repository permissions נותנים הרשאה אחת: **Contents: Read-only**.
4. מעתיקים את הטוקן. הוא מתחיל ב-`github_pat_`.

הטוקן נשמר בתוך קובץ האקסל, ולכן מגבילים אותו לקריאה בלבד ולמאגר הזה בלבד.

ב-Excel: Data → Get Data → From Other Sources → Blank Query → Advanced Editor:

```
let
    Token = "הדבק_כאן_את_הטוקן",
    Url = "https://raw.githubusercontent.com/yovav81/corp-market-data/main/data/latest.csv",
    Source = Csv.Document(Web.Contents(Url, [Headers = [Authorization = "token " & Token]]),
                          [Delimiter = ",", Encoding = 65001, QuoteStyle = QuoteStyle.Csv]),
    Promoted = Table.PromoteHeaders(Source, [PromoteAllScalars = true]),
    Typed = Table.TransformColumnTypes(Promoted, {
        {"date", type date}, {"security_id", type text}, {"last_price", type number},
        {"chg_pct", type number}, {"volume_k_nis", type number}, {"duration", type number},
        {"ytm_gross", type number}, {"ytm_net", type number}, {"coupon", type number},
        {"maturity", type date}}, "en-US")
in
    Typed
```

- כש-Excel שואל איך להתחבר, בוחרים **Anonymous**.
- החיבור לנתונים נעשה לפי `security_id`, שהוא מספר הני"ע.
- לחיצה על Refresh מושכת את הנתונים העדכניים.
- להיסטוריה מחליפים בכתובת את `data/latest.csv` ב-`data/history/2026.csv`.

## איכות הנתונים

- **ממשלתיות:** בטבלה של גלובס אין מספר ני"ע לאג"ח ממשלתיות, ולכן הן מזוהות לפי שם הסדרה, למשל `ממשל צמודה 0431`. לבניית עקום ממשלתי מספיקים המח"מ והתשואה.
- **אג"ח במצוקה:** סדרות כאלה מופיעות עם תשואות קיצוניות, למשל 9999, או עם תשואה שלילית חדה לפני פדיון. אקסל העל מסנן אותן מחישובי המרווחים.
- **סדרות בלי מסחר:** סדרה חדשה או סדרה בלי עסקאות עשויה להופיע בלי מח"מ ותשואה.
- **דירוגים:** הדירוגים מופיעים בכתיב של גלובס, למשל `AA-il` במעלות ו-`Aa3il` במידרוג. התבנית מזהה את הכתיב הזה.

## הערות

- **עלות:** במאגר פרטי GitHub נותן 2,000 דקות הרצה בחודש בחינם. הרצה אורכת כ-2 דקות, והשימוש החודשי נמוך מ-10% מהמכסה.
- **שעות:** השעות בקובץ ההרצה כתובות ב-UTC. לפעמים GitHub מעכב הרצה מתוזמנת בכמה דקות. הרצה שהתעכבה עד אחרי חצות נרשמת ליום המסחר הקודם.
- **תנאי שימוש:** הנתונים לקוחים מאתר ציבורי. מומלץ לבדוק את תנאי השימוש של גלובס ולהשאיר את המאגר פרטי.
- **הרצה במחשב:**
  ```
  pip install -r requirements.txt
  playwright install chromium
  python fetch_market.py --out data --xlsx
  ```

## היסטוריית מרווחים ל-3 שנים והתראות על מרווחים חריגים

- `data/hist/quarterly_spreads.csv` — המאגר ההיסטורי: מרווח ממשלתי, תשואה, מח"מ ומחיר לכל אג"ח ב-16 תאריכים רבעוניים (5.1.2023 – 21.10.2026), מתוך קובץ אקסל של יובב (מערכת מגמה). נוצר פעם אחת ב-`hist/import_quarterly.py <קובץ.xlsx>`; `ok=0` מסמן שורות שלא משמשות לחישוב (ממשלתי/מק"מ, ערכי זבל של 998%, מרווח שלילי, תשואה קיצונית). `data/hist/bond_static.csv` — הצמדה ודירוגים מנורמלים לכל אג"ח.
- `hist/hist_spreads.py` רץ בכל ערב אחרי `spreads.py` וכותב `data/hist/spread_stats.csv`: לכל אג"ח ממוצע/חציון/סטיית תקן/מינ'/מקס' של המרווח, המרווח הנוכחי (גלובס), אחוזון, **Z היסטורי** ו-**Z יחסי** (מול חציון קבוצת ההשוואה: הצמדה × קבוצת דירוג × טווח מח"מ, באותו תאריך). המדגם = הנקודות הרבעוניות + נקודת סוף-חודש אחת מגלובס לכל חודש שהסתיים, כך שההיסטוריה הופכת בהדרגה לחודשית. שתי השיטות נבדקו זו מול זו ל-21.10.2026: חציון ההפרש 0.00, רבעונים ±2 נ"ב.
- `hist/spread_alerts.py` מסנן מרווחים חריגים (ברירת מחדל: Z≥1.5 ו-40+ נ"ב מעל הממוצע, Z יחסי≥1, מח"מ≥1, מרווח≤12%, מדורגות בלבד; הורדת דירוג שנצפתה בגלובס → נפסל; דיווח חדש במאיה ב-14 הימים האחרונים למנפיק מסוקר → מסומן "לבדוק") וכותב `data/hist/alerts_latest.csv`, `alert_message.txt` (כיתוב), `alert_table*.png` (הטבלה כתמונה, עד 25 שורות לתמונה; `hist/alert_render.py`) ו-`alert_table.xlsx`. ההודעה נשלחת לטלגרם כתמונה + קובץ אקסל מצורף מתוך `market-data.yml` (אותם secrets כמו `corp-notify`). אג"ח חוזרת להתראה רק אחרי 7 ימים או אם ה-Z עלה ב-0.5 (`data/hist/alert_state.json`). הספים ניתנים לשינוי במשתני סביבה `ALERT_Z_ABS`, `ALERT_DEV_BP`, `ALERT_Z_REL`, `ALERT_MIN_DUR`, `ALERT_MAX_SPREAD`, `ALERT_INCLUDE_NR`, `ALERT_MAYA_DAYS`, `ALERT_REPEAT_DAYS`.
- `data/hist/peer_medians.csv` — חציון המרווח לכל קבוצת השוואה (כולל מח"מ) בכל תאריך; `data/hist/credit_conditions.csv` — חציון לפי הצמדה × קבוצת דירוג בלבד (מדד תנאי אשראי, מוצג בגיליון `תנאי_אשראי` באקסל העל עם גרף ואחוזון נוכחי).
- `hist/intra_issuer.py` — פערי מרווח בין כל זוג סדרות של אותו מנפיק: פער רגיל ב-3 שנים, פער היום ו-Z של הזוג (`data/hist/intra_issuer.csv`). זוגות עם Z≥2 ו-30+ נ"ב חריגה (אותה הצמדה, הסדרה הרחבה במח"מ≥1.5) נשלחים לטלגרם כתמונה שנייה ומוצגים בתחתית גיליון `מרווחים_חריגים`.
- באקסל העל (`corp/build_master.py`): גיליון `נתוני_היסטוריה`, עמודות ממוצע/מינ'/מקס'/Z/Z יחסי/אחוזון ב-`השוואה_אגחים` וב-`סינון_שוק`, התראה "מרווח חריג מול היסטוריה" (סף `p_z` בפרמטרים), וגיליון `מרווחים_חריגים` עם טבלת ההתראות.
- מגבלות: אג"ח מט"ח — יש להן היסטוריה אך אין מרווח יומי (גלובס/`spreads.py` לא מחשבים מט"ח), לכן אין להן Z. הדירוג לקבוצת ההשוואה הוא הדירוג הנוכחי. 16 נקודות ב-3 שנים הן מחזור אשראי אחד — Z הוא כלי סינון, לא תחזית לחזרה לממוצע.

## בוט מאיה — דיווחי חברות לתיקיות המנפיקים

תהליך נפרד (`maya-fetch`) שמושך ממערכת מאיה של הבורסה את כל הדיווחים הרלוונטיים של חברה לשלוש השנים האחרונות: דוחות כספיים (כולל XBRL), מצבות התחייבויות ובעלי עניין, תשקיפים, דוחות הצעת מדף, שטרי נאמנות, תוצאות הנפקה, דירוגים, מצגות, דוחות נאמן ואירועים מהותיים. דיווחים שוטפים (שינויי החזקות, מינויים, פתיחת מסחר) מדולגים.

- הפעלה: לשונית **Actions** → `maya-fetch` → **Run workflow** → שם חברה או מספר חברה במאיה. בדרך כלל Claude מפעיל את זה.
- התוצאה נדחפת לענף זמני `maya-out/<מספר ריצה>`: הקבצים ו-`catalog.csv` עם כל הדיווחים של החברה וההחלטה לגבי כל אחד (הורד / דולג ולמה).
- Claude ממיין את הקבצים לתיקיות `C:\CORP\02_Issuers\<מנפיק>\דוחות\...` לפי המוסכמה, מסנן כפולים לפי תוכן, ומוחק את הענף.
- ענפי `maya-out/*` אינם חלק מהמאגר הקבוע ואפשר למחוק אותם בכל עת.

## אג"ח קצרות — מח"מ מתחת ל-1 (short/)
התשואה הריאלית המצוטטת לאג"ח צמודה קצרה נכונה חשבונאית אבל מתעלמת מהמדדים שטרם פורסמו, ובאג"ח לשיעורין כל פדיון חלקי משנה את התמונה. לכן כל סדרה נבנית מחדש:
- `short/schedules.py` — מושך לכל סדרה קונצרנית עם מח"מ < 1.3 את "תזרים פירעונות" ופרטי האג"ח מביזפורטל (`bonds/quote/bondsdata/<ני"ע>`), פעם בשבוע לכל סדרה (`SHORT_REFRESH_DAYS`) → `data/short/bond_terms.csv`, `schedules.csv`.
- `short/cpi_expected.py` — המדד הידוע (הלמ"ס) + ציפיות לשנה מבנק ישראל (SDMX, dataflow `ZCM`: חזאים/שוק ההון/בנקים/חוזי אינפלציה) + עונתיות חודשית מ-6 השנים האחרונות → תוואי חודשי ל-18 חודשים `data/short/cpi_expected.csv`. דריסה ידנית לחודש: `data/short/cpi_manual.csv` (`ym,pct,source,as_of`). כשקובץ הממשלתי ייבנה, הציפיות מהעקום ייכנסו כאן (`SHORT_EXP_SOURCE`).
- `short/short_yields.py` — `short/engine.py` מחשב לכל סדרה: תזרים ל-100 ע.נ. נותרת, מקדם הצמדה L מהערך המתואם, תשואה ריאלית (IRR, סליקה T+1, ACT/365, ריבית שנתית), תשואה שקלית צפויה (כל תשלום × יחס המדד הידוע במועדו), מח"מ, פער מול גלובס ומרווח מול העקומים הממשלתיים באותו מח"מ → `data/short/short_bonds.csv`, `cashflows.csv`. אומת מול גלובס/ביזפורטל ל-28.10.2026: פערים של 0–2 נ"ב.
- באקסל העל: גיליון `מחמ מתחת ל 1` (`corp/short_sheet.py`) עם טבלת המדדים (תאים צהובים לדריסה ידנית) ותזרים חי לכל סדרה (XIRR) — שינוי מדד צפוי מתגלגל לכל הסדרות.
- `short/short_weekly.py` + `short-weekly.yml` — כל יום ראשון בבוקר: טבלת כל הקצרות כתמונה לטלגרם (ני"ע, סדרה, דירוג, הצמדה, מח"מ, תשואה גלובס, שקלית צפויה, מרווח שקלי, אינפלציה גלומה, תשלום קרוב, % קרן, ★ מסוקר/הערות; ממוין לפי מרווח, מצוקה בסוף) + אותה טבלה כאקסל.
